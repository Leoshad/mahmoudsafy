# Our Place — Mahmoud ♥ Safy

Implementation of the user-approved dark / muted pink / gold shared-chat direction. English UI, Arabic or English content. This supersedes the world experiment as the intended product; older files remain intact.

## Run and verify

Node 24.19.0, no third-party runtime dependencies. From `v2/place`:

```sh
npm run check
npm test
npm start
```

`npm start` requires the environment in `.env.example`. The app does not load `.env` implicitly. Keep actual secrets in Render environment settings, never in GitHub or chat.

## Implemented

- Optimistic human messages with a sending / delivered / failed state and idempotent retry. Authenticated server-sent events synchronize both people. AI streams separately, so its network wait does not hold the chat transaction.
- Supabase V2 password authentication with two explicitly allowlisted email addresses. No public registration or identity selector. A confirmed Supabase user ID becomes permanently bound to its assigned name. Encrypted HttpOnly SameSite cookies, server-side logout revocation, origin checks and a short auth verification cache.
- Shared photos with authenticated retrieval. The browser downsizes photos to 1280px and strips metadata by JPEG re-encoding. Server accepts at most 1 MB per photo and 150 MB total; MIME bytes are checked and SVG/HTML are refused. Uploads are shared-room material, not private-preparation attachments.
- Echo uses Responses streaming, `store:false`, `gpt-5.6-luna`, one model request per turn, and a 45-second timeout. Requests and photos are sent only when explicitly invited. Both people can stop shared AI; either person's Just Us pause persists. Ask once shares only its explicit prompt/image during Just Us and never releases a pause.
- Private, durable quiz drafts, edited manually or generated by Echo. Generated proposals require requester review. Only the draft owner can accept a proposal. Launch shares the current question; future questions and correct answers are absent from the partner's API. Questions support 2–4 choices or free responses, optional objective scoring, up to 10 questions, pause by either person, and complete vs abandoned results.
- Our Space: Ideas, Plans, Decisions, Agreements, Discussions, Photos, Results. Independent items with revision checks, completion/resolution, both people's agreement approvals, approvals reset on edits, explicit AI-memory permission, links back to source IDs. No deletion operation in this checkpoint.
- Persistent SQLite/WAL on a required production disk. Text export includes shared messages and only the requesting person's preparation. Restart recovery marks interrupted AI without automatic paid retry.

## Memory boundaries

Data is saved on the server. Each AI turn receives up to 50 recent AI-eligible messages, 30 memory-enabled notes and current activity answers, bounded to 24,000 context characters. Just Us messages and private preparation are excluded. Photos are never included automatically. This is bounded contextual memory, not a promise that all historical chat is always recalled. Text export is not a full database restore tool; keep a disk/database backup for full recovery. No end-to-end encryption claim: the hosting service holds the database and OpenAI processes explicitly shared AI content.
